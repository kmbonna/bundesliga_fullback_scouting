# **Full-Back Scouting Analysis – Bundesliga 2023/24 (IMPECT Open Data)**

This project is a full end-to-end football analytics case study on Bundesliga full-backs.

Using **IMPECT 2023/24 Bundesliga event data**, I built a complete pipeline to evaluate full-backs, engineer performance metrics, create thematic indices, and deliver a final scouting report supported by an interactive Tableau dashboard.

---

## **Key Objectives**
- Identify the most effective full-backs in the 2023/24 Bundesliga.
- Engineer custom thematic indices (progression, creativity, defensive stability, retention).
- Build reproducible Python pipelines for player-level aggregation.
- Build an interactive Tableau dashboard for player comparison and ranking.
- Produce a recruitment-focused scouting report.

---

## **Project Features**

### **Data Engineering**
- Cleaning and preprocessing IMPECT event-level datasets.
- Merging multiple event files into player-level datasets.
- Per-90 normalization and possession-adjusted metrics.
- Filtering by minutes played and position.

### **Feature Engineering**
- Progressive passing and carrying metrics.
- Deep completions and final-third involvement.
- Defensive duels, pressures, interceptions.
- Build-up involvement and width/inversion tendencies.

### **Custom Thematic Indices**
- **Progression Index**
- **Defensive Stability Index**
- **Creative Threat Index**
- **Retention & Ball Security Index**

### **Tableau Dashboard**
- Filters for club, position, FB-type, and minutes.
- Player radar charts and bar comparisons.
- Ranking table with custom indices.
- Player spotlight sections.

### **Final Scouting Report**
- Summary of methodology.
- Key insights and standout players.
- Shortlist recommendations based on tactical profiles.
